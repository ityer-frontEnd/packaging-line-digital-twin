# 包装自动化产线数字孪生

基于 Three.js 的单文件 3D 包装自动化产线数字孪生演示，包含：

- 10 工位完整包装产线
- 皮带输送测控单元精模与 19 个可点击部件
- 两台六轴工业机器人（真空吸盘装箱 / 夹板码垛）
- 实时趋势、特征提取、线性 SVM 故障诊断
- 卡滞 / 打滑 / 轴承温升故障演示与报警联动
- 可点击 SCADA 监控屏（5 页）
- 统一数据卡片放大、2~4 张并排对比、数据大屏
- 诊断报告导出、答辩模式

## 在线访问

GitHub Pages：https://ityer-frontend.github.io/packaging-line-digital-twin/

手机扫码或浏览器直接打开即可，无需本地服务器。

## 本地运行

直接双击 `index.html`。页面通过 CDN 加载 Three.js，首次打开需要网络连接。

### 快捷键

- `R` 复位
- `F` 注入卡滞故障
- `C` 电机剖视
- `E` 单元拆解
- `P` 答辩模式
- `Esc` 关闭弹窗 / 退出大屏

## 技术说明

所有 3D 几何体均由 Three.js 基础几何体代码生成，不使用 `.glb/.obj/.fbx` 外部模型。
